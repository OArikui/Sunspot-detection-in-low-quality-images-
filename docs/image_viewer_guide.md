# 画像確認ダイアログの操作ガイド

## 最終解析画像

最終解析画像の確認ダイアログは、Matplotlib のナビゲーションツールバーを使う利用者が迷わないよう、Home・Pan・Zoom を上部に配置しています。

| 操作 | 動作 |
| --- | --- |
| Home ボタン / Home キー | 画像全体が収まる初期表示へ戻す |
| Back / Forward | 直前・直後の表示範囲へ移動 |
| Ctrl + マウスホイール | カーソル位置を中心に拡大・縮小 |
| Zoom を選択して左ドラッグ | ドラッグした矩形の範囲へ拡大 |
| Pan を選択して左ドラッグ | 表示位置を移動 |
| Shift + 右ドラッグ | ツール選択状態に関係なく表示位置を移動 |

ダイアログ下部の HUD には、カーソル位置（画像ピクセル座標）と現在の X・Y 表示範囲が表示されます。画像座標は Matplotlib の `origin="lower"` に合わせ、左下を原点として扱います。表示範囲を変更しても、画像の縦横比は維持されます。

## マスク範囲の塗りつぶし

マスク選択ダイアログでは矩形の枠だけを表示します。選択したマスク範囲の半透明塗りつぶしは、**最終解析画像の確認ダイアログ**に重ねて表示します。表示はズーム・パンに追従し、画像左上原点で保存されたマスク座標をビューアーの左下原点へ変換して描画します。画像データやマスク処理の結果は変更しません。

`src/config.yaml` の `Display` で設定します。

- `show_mask_fill`: 塗りつぶし表示の有無（`true` / `false`）
- `mask_fill_color`: 塗りつぶし色（RGB、各値 0〜255）
- `mask_fill_alpha`: 不透明度（0〜255）。0 は透明、255 は不透明

`show_mask_fill: false` にすると、最終確認画面でもマスク範囲を塗りつぶしません。
